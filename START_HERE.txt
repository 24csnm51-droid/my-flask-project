SKILLSHARE PREMIUM FINAL — 2026 EDITION
========================================

SETUP
-----
1) Extract the ZIP and open the project folder in VS Code.
2) Open a terminal:
   cd project
   pip install -r requirements.txt
   python app.py
3) Open: http://127.0.0.1:5000

SECURITY VERIFICATION
---------------------
Learner registration and administrator security use a simple arithmetic CAPTCHA.
No SMS gateway, OTP message, or paid SMS credentials are required.
